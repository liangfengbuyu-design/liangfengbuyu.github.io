# 资治通鉴 · 卷一刷题器

《资治通鉴》卷一（周纪一，前 403 — 前 369）的记忆巩固工具。离线可用，可添加到手机桌面。

## 使用

直接打开网页即可。手机建议「添加到主屏幕」，从图标启动是全屏无地址栏的。

- **刷题**：顺序 / 随机 / 按事件 / 只刷错题
- **错题本**：答错自动收录，连续答对 2 次自动移出
- **统计**：累计正确率、分题型对比、事件强弱排行
- **继续上次**：答到一半关掉，下次接着答
- **备份**：设置页可导出 / 导入 JSON

学习数据只存在你自己的浏览器里，不上传任何服务器。

## 题库说明

30 道题全部标记为「待核对」——原文摘句尚未对中华书局点校本逐字核对，仅供记忆参考。
